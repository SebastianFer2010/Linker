# 🚀 Linker

> **Conectando el talento universitario con su primera oportunidad profesional.**

**Linker** es una plataforma y red profesional diseñada específicamente para estudiantes y recién egresados sin experiencia previa que buscan realizar sus **estadías, residencias profesionales o servicio social** en empresas que impulsan el nuevo talento.

---

## 📝 Descripción del Proyecto

A diferencia de las redes laborales tradicionales donde se requiere experiencia previa, **Linker** permite a los estudiantes destacar sus **proyectos académicos, habilidades técnicas, tecnologías dominadas y certificados**, eliminando la barrera de la "experiencia requerida" para puestos de entrada.

### ✨ Características Principales
* **Perfil de Estudiante / Becario:** Portafolio visual de proyectos universitarios, stack tecnológico y estado académico.
* **Portal para Empresas:** Publicación de vacantes enfocadas en estadías, prácticas profesionales y servicio social.
* **Match Inteligente:** Conexión directa entre vacantes de nivel entrada (*entry-level*) y alumnos en búsqueda activa.
* **Gestión de Postulaciones:** Seguimiento en tiempo real del estado de cada solicitud.

## 🛠️ Stack Tecnológico

* **Frontend:** [Angular 17+](https://angular.io/) (TypeScript, HTML5, CSS3)
* **Backend:** [Spring Boot 3+](https://spring.io/projects/spring-boot) (Java 21, Spring Web, Spring Data JPA)
* **Base de Datos:** MySQL / PostgreSQL
* **Herramientas & Entorno:** Node.js, npm, Maven, Git, GitHub Desktop

## 📋 Requisitos Previos

Para ejecutar **Linker** de forma local, asegúrate de contar con las siguientes herramientas instaladas en tu equipo:

1. **Java Development Kit (JDK 17 o 21):**
   * Comprobar versión: `java -version`
2. **Node.js (v18.x o superior) y npm:**
   * Comprobar versiones: `node -v` y `npm -v`
3. **Angular CLI:**
   * Instalar globalmente: `npm install -g @angular/cli`
   * Comprobar versión: `ng version`
4. **Spring Boot CLI / Maven:**
   * Comprobar versión: `spring --version` o `./mvnw -v`
5. **Servidor de Base de Datos (MySQL / PostgreSQL):**
   * Activo y accesible en el puerto local correspondiente (ej. `3306`).
